API Monitor (“the app”) is published by <YOUR NAME OR COMPANY>. This page describes what data the app does and does not collect.

Summary

  • API Monitor does not collect, transmit, or sell personal data.
  • The app makes HTTP requests only to the URLs you configure, on the schedule you set.
  • All configuration and history is stored locally on your device and is excluded from cloud backups.

The app does not include analytics, ad SDKs, crash reporting services, or any third-party tracker.

Permissions used

  • INTERNET — to call the APIs you configure.
  • POST_NOTIFICATIONS (Android 13+) — to alert you when a monitored API changes state. You can revoke this anytime in system settings.
  • ACCESS_NETWORK_STATE — to avoid running checks when offline.
  • WAKE_LOCK / FOREGROUND_SERVICE — used by Android WorkManager to run scheduled checks reliably.

Children

The app is not directed at children. It does not knowingly collect data from anyone, including children.

Your control

  • Delete an API to stop monitoring and remove its history.
  • Uninstall the app to remove all locally stored data.
  • Revoke notification permission in your device settings.
